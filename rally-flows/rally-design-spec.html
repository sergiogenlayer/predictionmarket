Create a Campaign — Spec

El flujo de crear campaña, pantalla a pantalla, componente a componente: cada elemento numerado sobre el mockup y especificado en la tabla — tipo, copy final en inglés, estados y comportamiento. Regla global: el flujo es uno solo; las 3 entradas solo deciden en qué pantalla entras (ver S0). Colores, tipografía y componentes base: los del design system actual de Rally.
